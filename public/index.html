客户端怎么用

  1. 在订阅卡片选覆写脚本：精简（推荐，分流组：Google、NovelAI、AI、Apple、Telegram、Steam、AdBlock）或全量（另加 YouTube、Netflix、GitHub、Microsoft 等）。
  2. 按「复制链接」或「一键导入 Clash」，在 Clash Verge Rev / Mihomo Party / FlClash / Bettbox 等 mihomo 客户端添加远程订阅，并打开自动更新。 链接已经套用好脚本，客户端不要再加脚本覆写，否则会覆写两次。
  3. 关闭客户端的 DNS 覆写（MyClash 脚本要求）。
  4. iPhone 用小火箭：订阅卡片选「小火箭」，先按「导入节点到小火箭」，再按「导入分流配置」（分流组同精简版）。详细步骤与省电设置见下方「iPhone 小火箭教程」。

两个版本都是 AIsouler/MyClash 脚本的修改版：分流组用各自服务的网址测速（参考 Bettbox 的服务检测），HuggingFace 不走「AI」组、改走「默认代理」。 已到期或流量用完的机场会在合并时自动屏蔽，客户端显示的流量与到期日也不计入它。

iPhone 小火箭教程（导入与省电）

小火箭读不了 mihomo 的规则集，所以节点和分流分开导入：订阅只给节点，分流用 /shadowrocket.conf。 这份配置的分流组同精简版，规则集改用 blackmatrix7 的小火箭 .list，没有 HuggingFace 分流，广告规则只用 AdvertisingLite。AI 默认台湾，订阅里没有台湾节点时手动改选「美国」；要固定用某个节点，在地区组里选「<地区>-节点」。

  1. 用非中国区的 Apple ID 在 App Store 购买安装 Shadowrocket。
  2. 用 iPhone 的 Safari 打开本页，导入订阅，订阅卡片选「小火箭」。
  3. 按「导入节点到小火箭」，确认添加订阅。也可以手动添加：首页右上角「+」，类型选 Subscribe，贴上订阅链接。
  4. 按「导入分流配置」，在小火箭「配置」页点 shadowrocket.conf →「使用配置」。也可以手动添加：「配置」页右上角「+」，贴上配置链接。
  5. 首页「全局路由」选「配置」，打开连接，第一次连接时允许添加 VPN 配置。
  6. 自动更新：先在系统「设置 → 通用 → 后台 App 刷新」允许 Shadowrocket；再到小火箭「设置 → 自动更新」： 「订阅」（即节点，小火箭叫「服务器」）间隔选 24 小时。 分流配置不自动更新（规则集照样会自动刷新），手选结果不会被重置；本仓库改了配置时，删掉旧的再按「导入分流配置」。

息屏断开、亮屏自动连上（iOS 不允许 App 监听锁屏，这是最接近的做法）：

  • 「设置 → 按需求连接」：打开，添加「Wi-Fi」与「蜂窝网络」规则，动作选「连接」；不要开「始终开启」：它让 VPN 任何时候都保持连接、断了就自动重连，跟息屏断开省电的目的相反。
  • 打开「睡眠时断开」：设备睡眠时断开，亮屏后有 App 联网时 iOS 会自动重连。息屏后 iOS 不一定马上睡眠，所以不是一锁屏就断；如果推送常收不到，就关掉这项。

更省电：只在用特定 App 时开 VPN。「快捷指令 → 自动化 → App」：选 Claude、Telegram 等，「已打开」时运行「启动 Shadowrocket」，「已关闭」时运行「停止 Shadowrocket」，都设为立即运行。用这个方法就不要同时开按需求连接。 地区组（香港、日本…）默认选「<地区>-自动选择」自动挑最快的；想固定某个节点，就在地区组里直接点它，重连 VPN 也会保留。 另外，全局路由保持「配置」，不装模块、不开 MitM；配置里的测速间隔为 10 分钟，不要改小。

安全提醒

每个订阅链接里的 TOKEN 都等同密码，拿到的人就能用你的节点，也能编辑或删除这个订阅。如果外流了，按「换 TOKEN」，旧链接会立刻失效，再把新链接贴回客户端就好。

全选 / 全不选作用于所有机场里符合搜索的节点；展开机场后按住 Shift 点击可以连选。

4AI 链式代理 选填

选中的节点直接经「AI链式代理」组中转（默认香港，客户端里改选后会记住；选「直连」就是不中转），不复制节点、不多出组，它们只留在整组的地区组与「AI」组（从手动选择等其他组拿掉，那些组才能当中转）； 「AI」组默认选第一个整组，没选整组就默认选第一个节点。适合只能经中转连上的家宽节点。只对精简 / 全量覆写的链接生效。

整组

点一下选整个地区组，组里每个节点都经中转，例如选「台湾」，AI 默认选的「台湾」组就是链式代理。数字是会导入的节点数，按名称估算。
